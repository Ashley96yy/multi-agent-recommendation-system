# Provenance and reuse policy

This repository is an independent portfolio implementation inspired by the SJSU DATA 298A Team 5 Topic 22 research direction.

Original team repository: https://github.com/Ashley96yy/data298a-team5-topic22

## Reuse policy

- Do not copy team-owned code, data, pretrained checkpoints, or experiment artifacts without checking contributor attribution, applicable licenses, and course sharing rules.
- Develop new modules independently; record any later reuse with source path, commit, author, permission, and modifications.
- Published metrics must come from verified runs of this repository. Team results cannot be presented as results of this system.
- Do not commit private user histories, proprietary data, secrets, or licensed dataset copies.
