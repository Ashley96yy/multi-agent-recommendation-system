# Synthetic sample catalog

All entries in `catalog.json` are fictional and intentionally marked SYN. They are
for contract validation and deterministic tests only; no consumer purchase or
product-performance claim is implied.

This sample contains: one explicitly fragrance-free product with a stated
price, one explicitly fragranced product, and one product with unknown price
and unverified fragrance status. Missing values must remain unknown.

The presence of a reference means an excerpt was supplied; schema validation
does **not** prove the excerpt actually supports the claim. That requires the
later evidence-verification module and evaluation.
